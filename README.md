## 产品简介

SkillSwap 是一个技能互换匹配平台，解决两个核心痛点：

- **想学新技能但报班贵、自学难坚持** → 平台帮你找到互补的人，互相教
- **自己擅长的技能缺少分享和变现渠道** → 用技能换技能，不再是单向付出

### 核心闭环

1. 用户填写「我能教的」和「我想学的」
2. 系统做**双向互补匹配**：你想学的正好是他能教的，他想学的正好是你能教的
3. 一键发起交换，约时间互相教学
4. 完成后互评，积累信任

## 页面结构

| 路由 | 功能 |
|---|---|
| `/` | 首页：价值主张 + 热门技能 + 推荐交换 |
| `/explore` | 技能广场：浏览所有人的"能教 / 想学" |
| `/post` | 发布：我能教 / 我想学 双表单 |
| `/match` | **智能匹配**：双向互补撮合（核心亮点） |
| `/profile` | 个人主页：我的技能、交换记录、评价 |

## 技术栈

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- 纯前端 Mock 数据，无后端依赖
- 一键部署至 Vercel
